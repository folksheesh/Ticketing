# Custom Fonts Directory

Silakan letakkan file font **Accia Piano Bold Italic** di dalam folder ini (`frontend/src/assets/fonts/`).

Nama file yang didukung:
- `AcciaPiano-BoldItalic.ttf` / `AcciaPiano-BoldItalic.otf` / `AcciaPiano-BoldItalic.woff2` / `AcciaPiano-BoldItalic.woff`
- ATAU `AcciaPiano.ttf` / `AcciaPiano.otf`

Setelah file ditaruh di folder ini, aplikasi akan otomatis memuat dan menampilkan font **Accia Piano Bold Italic** untuk logo dan tulisan **DENSO**.
